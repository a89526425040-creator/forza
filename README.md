# Open Horizon

Первый игровой прототип открытого автомобильного мира на Godot 4.4.1.

## Текущий этап
- Тестовая европейская альпийская дорога.
- Процедурный blockout спортивного купе в духе BMW M4 (это временная геометрия, не финальная модель BMW).
- Камера из салона.
- Экранные кнопки газа, тормоза и поворота.
- Android APK собирается через GitHub Actions.

## Запуск
Откройте проект в Godot 4.4.1 и запустите `main.tscn`.

## План
1. Стабильная физика и управление на Android.
2. Детализированная модель BMW M4 и интерьер.
3. Европейский город, автобаны, Альпы и переходы между районами.
4. Потоковая загрузка мира, LOD и оптимизация.
5. Гонки, трафик, полиция, карьера, тюнинг, дождь и смена времени суток.

Цель проекта — большой открытый мир около 1000 км². Эта цель не означает, что вся территория уже присутствует в первом прототипе.
